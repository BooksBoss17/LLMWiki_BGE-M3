# 2025高考真题答案格式变体及配对策略

## 答案格式变体

| 格式 | 示例 | 出现省份 | 正则 |
|------|------|---------|------|
| 英文句号 + 【答案】 | `1.【答案】D` | 安徽/福建/河南/辽吉黑蒙/陕晋青宁/上海/云南 | `^(\d+)\.\s*【答案】\s*(.*)` |
| 中文句号 + 【答案】 | `1．【答案】D` | 河北/湖南 | `^(\d+)．\s*【答案】\s*(.*)` |
| 兼容两者 | — | — | `^(\d+)[\.．]\s*【答案】\s*(.*)` |

## 答案和解析的排列方式

### 方式A：答案和解析在同一行
```
1.【答案】D 【解析】根据...
```
→ 答案和解析作为一个 block，按题号配对

### 方式B：答案和解析分行交替排列
```
1.【答案】D
【解析】根据...
2.【答案】B
【解析】由题意...
```
→ **不能按 block 序号配对**（27 blocks / 15 题），必须按题号 `N` 配对：
1. 找所有 `N.【答案】` 行，提取题号和答案
2. 找紧随其后的 `【解析】` 块作为详解
3. `N.【答案】` 到下一个 `N.【答案】` 之间的全部内容属于第 N 题

### 方式C：计算题只有【答案】无【解析】
```
14.【答案】(1) 小球从最下端...
15.【答案】(1) 第1根导体棒...
【解析】详细答案和详细解答过程见答案
```
→ `【解析】` 为占位符，实际解答在 `N.【答案】` 块中
→ 将 `N.【答案】` 的完整内容放入详解字段，答案字段填"见详解"

## 试卷和解析在同一份 DOCX 的分割

高考真题通常是"题目+解析在卷尾"格式：
1. 在 MD 中搜索"答案和解析"标记作为分割线
2. 前半部分是题目区（按 section 分）
3. 后半部分是答案区（按 `N.【答案】` + `【解析】` 配对）

## 特殊省份

- **上海卷**：只有一个"综合题"大 section，每题有多个小问，题量少但每题分值大（6题 vs 其他省15题）。所有题类型为 C（计算题）。
- **山东卷**：18题（比其他省多3题）。
- **浙江1月卷**：20题（最多）。
