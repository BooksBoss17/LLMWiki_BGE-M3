# 讲义设计文档提取

## 何时使用

当讲义已完成导入（合并版 MD 含题目+答案+详解），用户要求提取"讲义设计"文档时使用。讲义设计文档面向教师，提取知识点体系和选题逻辑，与面向学生的讲义本体互补。

## 输入

- 讲义合并版 MD：`raw/lectures/讲义XX-标题/讲义XX-标题.md`
- 讲义结构：考情分析 → 题型N（知识点讲解 + 典例 + 变式）→ 链接高考

## 输出

- 讲义设计 MD：`raw/lectures/讲义XX-标题/讲义XX-标题_设计.md`
- Wiki 页：`LLMWiki/concepts/设计-讲义XX-标题.md`
- RAG：source_type=lesson_design（rag_pipeline.py 已支持 `_设计` 文件名识别）

## 讲义设计 MD 格式

```markdown
---
title: 讲义XX-标题 — 讲义设计
type: lesson_design
tags: [model, lesson-design, physics, 知识点分类]
sources: [../raw/lectures/讲义XX-标题/讲义XX-标题.md]
---

# 讲义XX-标题 — 讲义设计

## 考情分析
（分值占比、题型分布、命题方向、核心考查内容）

## 题型设计与知识点体系
### 题型一：XXX
**知识点凝练：** 核心概念、分析方法、关键公式（LaTeX）
**选题逻辑：** 典例选择意图 + 变式设计意图（在典例基础上变了什么）
**教学策略：** 引入方式、难点突破、易错点提示

## 选题梯度设计
| 层级 | 题目 | 考查重点 | 难度 |
|------|------|---------|------|
| 典例 | 典例1 | 核心方法 | 基础 |
| 变式 | 变式1-1 | 方法迁移 | 中档 |
| 高考 | 链接高考1 | 真题实战 | 高考 |

## 教学建议
课时安排、重点题型、学生易错点、章节关联
```

## 实现方式

用 delegate_task 一次性处理多个讲义（如16份），子 agent 逐个读取讲义 MD，提取设计文档。纯文本+LaTeX，无图片引用。

## RAG 集成

rag_pipeline.py 讲义扫描段已支持 `_设计` 文件名识别：
- `讲义XX-标题.md` → source_type=lecture
- `讲义XX-标题_设计.md` → source_type=lesson_design

教师在备课时检索"力与物体的平衡 教学设计"可命中讲义设计 chunks。
