### 关键发现

1. **EQ 域代码是最常见的公式格式**（489 个，占 34%），但之前被误认为"纯文本公式丢失"
2. **同一文档中经常混合 2-3 种格式**，需要 `omml_docx_to_md.py` 统一处理
3. **WMF/OLE 集中在 06/07/11/12 专题**（Equation Editor 3.0 生成）
4. **纯文本残留**（上标丢失 `R2`→`R²`，变量 `*x*`）是所有格式的共同局限，非工具问题

### ECMA-376 标准说明

- EQ 域代码不在 ECMA-376 标准中定义
- 标准 §17.16.2 只规定了 `fldChar`/`instrText` 的 XML 存储结构
- EQ switch 语法 (`\f`, `\r`, `\o\al` 等) 是 Word 二进制时代遗留
- 本 skill 的 switch 映射基于从 489 个实际域代码逆向分析得出
