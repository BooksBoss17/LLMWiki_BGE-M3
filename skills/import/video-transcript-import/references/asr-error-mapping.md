# ASR Error Mapping — faster-whisper large-v3 中文物理术语识别错误

faster-whisper large-v3 对中文物理术语的语音识别存在系统性同音字错误。
以下错误从 25 个实际导入视频的转写稿中收集，按物理领域分类。

## 使用方法

- 知识笔记和教学简案：**必须全部修正**
- 逐字稿：可保留原始转写或修正，修正时在文末注明修正记录
- subagent 生成三层文件时，在 context 中列出该视频的已知 ASR 错误，让 subagent 修正

## 模式总结

ASR 错误的根因是 whisper 对中文同音字/近音字的识别偏差，主要集中在：

1. **声调错误**：震→振（四声→一声）、云→匀（二声→二声但发音不同）
2. **形近字误读**：电视→电势（视/势同音）、便利→变力（便/变同音）
3. **物理符号口语化**：那么大→λ（"那么大"是口语读法）
4. **专业术语不常见**：楞次→能词（whisper 不认识"楞次"）
5. **多音字**：重→纵（重波→纵波）

## 给 subagent 的修正指令模板

在 delegate_task 生成三层文件时，context 中加入：

```
注意：转写稿中ASR识别错误，请在输出中修正：
- 电视能→电势能，电视→电势，电厂→电场
- 能词→楞次，词通量→磁通量，词场→磁场
- B和→闭合，安排力→安培力
- 云墙→匀强，出速度→初速度
逐字稿中保留或修正，知识笔记和教学简案中必须全部修正。
```
