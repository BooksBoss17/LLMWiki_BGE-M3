# 三层文件模式：逐字稿 + 知识笔记 + 教学简案

## 设计原则

B站教学视频转写后不直接导入 RAG——口语噪音和时间戳会干扰语义匹配。
而是生成三层文件，各司其职：

| 文件 | type | 面向 | RAG切片 | 图片引用 | 特点 |
|------|------|------|---------|---------|------|
| 逐字稿 | transcript | 存档/回溯 | ❌ | ✅ | 完整保留口语+时间戳 |
| 知识笔记 | knowledge_notes | 学生/检索 | ✅ | ❌ | 去口语化，纯知识点+LaTeX公式 |
| 教学简案 | lesson_plan | 教师/备课 | ✅(可选) | ✅ | 教学流程+策略+关键帧引用 |

## 生成方式

通过 `delegate_task` 交给子 agent 一次性生成三份文件：
- 传入：转写稿 JSON 路径 + 关键帧 VLM 识别结果 + 输出文件路径
- 子 agent 读取转写稿后生成三层文件
