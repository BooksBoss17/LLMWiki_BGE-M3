# 关键帧拼图审阅与补抽策略

## 适用场景

初次按转写稿抽帧后，关键帧中出现以下问题：

- 老师身体/手臂遮挡核心板书。
- 帧落在公式书写中，结论未完成。
- 大字特效/弹幕/字幕遮挡题干或公式。
- 单帧目标写得过宽，VLM 误判“不完整”。

## 推荐流程

1. **先生成 contact sheet**：每 4 张关键帧拼成 2×2 图，每格左上角写 `编号 + MM:SS + 秒数`，减少 VLM 调用次数，也方便横向比较。
2. **逐 sheet VLM 审阅**：要求 VLM 逐格提取文字/公式/图示，并按“局部目标”判定：完整 / 基本完整 / 不完整 / 被遮挡需重抽。
3. **不要机械保留初抽帧**：过渡帧、未写完帧、遮挡帧应从最终 manifest 中剔除，即使它们是 LLM 推荐时间点。
4. **补抽候选要围绕问题帧前后找**：按 ±20–120 秒抽多个候选，再做第二轮 contact sheet；不要盲目只后移 5 秒。
5. **最终帧宁少勿滥**：只引用 complete/basic 帧。若某视频短，5–7 张高质量关键帧优于 10 张遮挡帧。
6. **manifest 写清替换原因**：`keyframe_candidates.json` 中记录最终帧、VLM 完整性、选择说明；`keyframe_vlm_notes.md` 记录未采用帧的问题与最终采用帧。

## Prompt 模板

```text
这是“<视频主题>”视频的关键帧拼图。每格左上红字是帧编号和时间。
请逐格提取画面中所有可读文字、公式、图示要点；并仅按该帧局部目标判断是否完整
（完整/基本完整/不完整/被遮挡需重抽）。输出中文结构化列表。
```

补抽候选：

```text
这是“<视频主题>”视频的补抽候选帧拼图。每格左上红字是候选编号和时间。
请逐格判断板书是否清晰完整，提取主要公式/内容，并推荐可替换原先被遮挡关键帧的候选编号。
```

## 经验

- 对板书课，最终帧应偏向“写完后的总结帧”，而不是老师刚开始写的讲解帧。
- 如果知识点天然分段，用多帧分别承担“模型图/公式链/结论/例题”的局部目标，不要求单帧覆盖全部内容。
