# Wiki 页面结构化拆分格式模板

## 三级结构

```
书索引页 (1个)     → 书总结 + 章目录链接
├── 章索引页 (N个)  → 章总结 + 节目录链接
│   ├── 节摘要页 (M个) → 节摘要 + 关键知识点 + 例题 + 提问 + 节练习概括
│   └── ...
└── ...
```

## 文件命名规则

- 书索引: `physics-textbook-vol1.md` / `physics-textbook-selective1.md`
- 章索引: `physics-textbook-vol1-第N章-章名.md`（保持原文件名）
- 节摘要: `physics-textbook-vol1-第N章-第M节-节名.md`（新建）

## 摘要原则速查

| 内容类型 | 处理方式 |
|---------|---------|
| 叙述性段落 | 浓缩 1-2 句 |
| 定义/公式/定律 | 保留原句 |
| 例题+答案 | 保留原句 |
| 课本提问 | 保留原句 |
| 节练习/章末练习 | 一句话概括 |
| 图片引用 | 保留路径 |

## 并行处理

多本教材时用 `delegate_task` 每本一个子 agent：
- 每个 agent 处理 1 本教材的全部章节
- 必须传入：wiki concepts 目录路径、raw 教材目录路径、格式要求
- 可参考已完成的教材格式（如必修一）

## H3 边界识别

教材章节页中 H3 (`###`) 标记节边界。但注意：
- H3 标题可能被 OCR 污染（如 `### 导入` 后面跟着节标题）
- 部分教材的节标题被 marker OCR 拆成多行
- 实际拆分时需人工判断哪些 H3 是真正的节边界，哪些是栏目标题
- 栏目标题（节练习、例题、迁移、策略提炼等）归入上一节，不单独成页
