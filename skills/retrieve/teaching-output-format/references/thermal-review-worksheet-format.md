# 热力学/物理复习练习卷格式与内容设计（基于本校样卷）

用于把知识库题目与复习重点生成 Word 练习卷。适用于用户要求“参考过去制作的卷子格式”“讲义/练习多一个知识点栏”的场景。

## 触发条件

- 用户要求生成期末复习讲义/练习，并提供本校历史卷作为格式参考。
- 用户指出内容太多、重点不清，需要根据近期复习卷/质检卷分布缩减。
- 用户要求“格式大差不差，只是多知识点一栏”。

## 格式规范（优先遵循）

参考用户历史卷：

- A4 单栏。
- 四边距 2 cm。
- 标题：居中，14 pt，加粗。
- 正文：10.5 pt。
- 中文字体：宋体。
- 西文、数字、公式变量：Times New Roman；公式用 OMML。
- 行距：1.0。
- 题目/选项：沿用练习卷风格，题干和选项可加粗。
- 答案表：末尾用 2 行表格（题号/答案）。
- 每道题外包一张 2 列表格：左列“知识点”，右列“题目内容”。左列浅灰底或窄栏，宽约 2.2 cm；右列宽约 13.8 cm。

> 注意：这是“标准练习卷格式”，不是压缩讲义格式。不要默认使用双栏、蓝色标题、微软雅黑或 7 pt 小字，除非用户明确要求极限压缩。

## 内容拆分策略

如果热学复习内容过多，不要硬塞成一份。优先拆成两份：

### 练习1：基础概念 + 气体定律 + 实验

建议模块：

1. 分子动理论：布朗运动、扩散、分子力/势能、温度与内能。
2. 气体实验定律：`pV=C`、`p/T=C`、`V/T=C`、`pV/T=C`。
3. 液柱/活塞基础模型：先定压强，再列状态方程。
4. 热学实验：探究气体等温变化规律；油膜法只保留一道小题。

题量建议：选择/判断 8 题 + 实验/计算 3–4 题。

### 练习2：气体图像 + 热一律 + 综合应用

建议模块：

1. 气体图像：`p-V`、`p-T`、`V-T`、`p-1/V`。
2. 热力学第一定律：`ΔU=Q+W` 及符号判断。
3. 理想气体内能：只由温度决定。
4. 循环过程、等温/绝热/等压/等容过程。
5. 热二律、固液概念只做少量选择题。
6. 情境应用：洗衣机水位传感器、报警器、气缸弹簧等。

题量建议：选择/判断 9 题 + 实验/计算/综合 3 题。

## 根据近期卷子确定重难点

生成前先统计或检索近期复习卷/质检卷题库来源，不要凭教材目录平均铺开。对本校热学期末复习，已验证的高频主线是：

1. 热力学第一定律：`Q/W/ΔU/循环过程`。
2. 气体实验定律：液柱、活塞、气缸、传感器情境。
3. 气体状态变化与图像。
4. 探究气体等温变化实验。
5. 分子动理论概念辨析。

低频内容：固体液体、热力学第二定律、油膜法。保留但压缩成概念判断或小题，不要展开成大段讲义。

## 质量检查

- 用 Word COM 实测页数，不能只看 DOCX 大小。
- 导出 PDF 并检查每页有文字、无空白页。
- 抽查 `document.xml` 中是否含 `<m:oMath`，确保公式为 OMML。
- 抽查标题 run：`eastAsia=宋体`，`ascii=Times New Roman`，字号 14 pt。
- 抽查边距为 2 cm，表格数量符合“知识点栏+答案表”结构。

## 常见坑

1. 用户说“参照卷子格式”时，不要沿用之前的压缩讲义样式。标准卷是宋体、TNR、10.5 pt、A4 单栏、2 cm 边距。
2. 内容太多时优先拆成两份练习，而不是把字号压到不可读。
3. 知识点栏是本任务的关键差异：每道题左侧都要可见，不能只在题目前写括号标签。
4. 热学复习不应按教材三章平均分配篇幅；应把大部分篇幅给气体定律、气体图像、热一律。
