## 输出结构

输出适合高中物理教师备课的紧凑材料。必须包含：

1. **专题定位**：说明章节位置和核心难点。
2. **必备知识清单**：感应、电路、安培力、运动、能量、动量之间的联系。
3. **模型分类**：
   - 单杆：匀速切割、自由加速/减速、恒力牵引、含电阻/电源/电容、终端速度。
   - 双杆：同向/反向、等质量/不等质量、单回路/双回路、光滑/有阻力、是否受外力。
4. **通用解题流程**：判磁通量变化和电流方向 → 建等效电路 → 求安培力/功率 → 选择动力学、能量或动量方程 → 检查极限状态。
5. **单杆方法模板**：给出常用公式、方程选择和典型终态。
6. **双杆方法模板**：处理相对运动、电路耦合、动量-能量关系和热量分配。
7. **易错点与检查清单**：方向、符号、电阻分配、有效长度、功率/热量、终端条件。
8. **来源依据**：简要标注来源类型，例如 `[教材:选必2-第2章]`、`[讲义:电磁感应]`、`[题库:电磁学]`。

## 方法规则

- 始终区分物理模型和代数公式。
- 对电流-安培力耦合，写清因果链：`v -> E -> I -> F_A -> a -> v变化`。
- 方向题按“磁通量变化 → 楞次定律 → 右手定则或电流受力关系”的顺序说明。
- 终端速度题先明确加速度或合力为零，再求解。
- 能量题区分外力做功、动能变化、电能和焦耳热。
- 双杆题先判断关键变量是绝对速度还是相对速度；感应电动势常取决于相对切割速度。
- 用动量前必须检查所选方向是否有外力；否则改用冲量动量或能量-动力学耦合。

## 公式风格

公式保留 Markdown LaTeX，便于 DOCX 导出器转成 OMML：

- 动生电动势：`$E=BLv$`，相对形式 `$E=BL(v_1-v_2)$`。
- 电流：`$I=E/R_{\text{总}}$`。
- 安培力：`$F_A=BIL$`。
- 电功率和热量：`$P=EI=I^2R$`，`$Q=\int I^2R\,dt$`。
- 电荷量：`$q=\Delta\Phi/R_{\text{总}}$`。
