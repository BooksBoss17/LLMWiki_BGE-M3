# 题库知识点标签目录

> 本文档是题库 `knowledge_points` 字段的唯一标签来源。之后**不再通过整理 `raw/exercises/` 目录来表达知识点分类**；raw 目录只作为物理存储位置，题目的知识点以 frontmatter 的 `knowledge_points` 多标签为准。

本 skill 归 Role D 管理。机器权威 ID registry 是
`references/knowledge-points.yaml`；本文档保留教师可读目录。`kp_id` 永不复用，
改名或移动保留旧路径 alias，删除以 `deprecated + replacement_ids` 表示。

本 skill 是 `knowledge_points`、`knowledge_point_ids` 和稳定 `kp_id` 的唯一写入入口。其他 Role D skills 可以提出候选，但不得直接写正式字段或分配 ID。

## 安全管理入口

所有变更先生成 proposal 并 dry-run：

```bash
python skills/taxonomy/exercise-knowledge-tags/scripts/manage_taxonomy.py \
  --proposal <taxonomy-change.json> --dry-run --json
```

任何 apply 都要求 `--teacher-authorized`；改名、移动、停用等破坏性变更还要求
`--allow-destructive`。禁止直接手改 registry 后跳过环路、alias 和稳定 ID 校验。
弱模型生成 proposal 前必须读取 `references/taxonomy-change-schema.md`，逐字段使用固定 action；不得用语义近似的自创字段替代脚本接口。
强模型也必须读取同一 schema。`strong` 可比较别名、父级和题目覆盖情况，但不得自创字段、预分配可复用 ID 或扩大 apply 权限。

## 使用规则

1. 每道题的标准 `knowledge_points` 优先从下方标签目录中选择，可多选。
2. 新导入或被 Role D 编辑的题目同时写 `knowledge_point_ids`；ID 与中文路径必须对应。
3. 综合题、实验题、跨模块题允许赋予多个标准标签；优先标注到最具体的三级标签，必要时同时保留二级标签。
4. 除标准标签外，AI 可以根据题目内容额外添加自主判断标签；为避免污染标准知识点索引，写入 frontmatter 的 `ai_extra_tags` 字段，不得混入 `knowledge_points`。
5. `ai_extra_tags` 是自由扩展标签，可用于题型特征、解法方法、情境主题、易错点、能力维度等；命名应短小清晰，如 `多过程建模`、`图像法`、`临界条件`、`易错-单位换算`。
6. 新增标准标签必须先更新机器 registry；自由扩展标签不需要修改 registry。strong curator 可在题目校对或绘图写回时顺手维护 `ai_extra_tags`，本 skill 的 `assign_question` 也支持单独更新该字段。
7. raw 目录不再作为知识点分类依据，不再为了分类而移动题目文件。
8. Wiki/RAG 继续使用中文 `knowledge_points`，避免改变 BGE-M3 parser；StudentDataSQL 只通过稳定 `kp_id` 联动。

## 建议的题目 frontmatter 写法

```yaml
knowledge_points:
  - 力学/匀变速直线运动/运动图像
  - 力学/牛顿运动定律/牛顿第二定律
knowledge_point_ids:
  - kp_000018
  - kp_000032
ai_extra_tags:
  - 图像法
  - 多过程建模
  - 易错-单位换算
```

> 说明：`knowledge_points` 建议采用 `一级/二级/三级` 的完整路径，避免同名标签歧义（如“能量守恒定律”在力学与热学背景下含义不同）。`ai_extra_tags` 为 AI 自主扩展标签，不参与标准知识点合法性校验。

## AI 自主扩展标签

AI 录入或维护题目时，除按本目录写入标准 `knowledge_points` 外，可以额外添加 `ai_extra_tags`：

- **解法/方法**：`整体法`、`隔离法`、`图像法`、`等效法`、`临界条件`、`守恒法`
- **题型特征**：`多过程问题`、`组合场`、`实验设计`、`数据处理`、`图表分析`
- **能力维度**：`建模能力`、`推理论证`、`数学运算`、`信息提取`
- **易错提醒**：`易错-方向判断`、`易错-单位换算`、`易错-符号约定`
- **教学用途**：`适合课堂例题`、`适合课后巩固`、`适合压轴训练`

自由扩展标签应服务于检索、备课和教学分析；不要替代标准 `knowledge_points`。
每题最多 16 个，每项 2–32 字符；不得包含标准路径分隔符 `/`，不得使用 `kp_XXXXXX` 形式。
