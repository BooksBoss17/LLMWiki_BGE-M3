# LLMWiki 内容索引

本文件是 Wiki 库的内容目录占位页。

开源发布版本不包含原作者的本地知识库内容（Wiki 页面、题库、教材、讲义与视频转写均未发布，见仓库根 README 的 Data 一节）。

## 如何生成你自己的 Wiki 页面

1. 将你自己的资料清洗为自包含 Markdown 后放入 `LLMWiki/concepts/`；
2. 页面之间使用 `[[wikilinks]]` 建立关联，本库附带 Obsidian 配置（`.obsidian/`）可直接用 Obsidian 打开；
3. 每新增或调整页面后，在本文件登记目录条目，并同步更新 `log.md`。

页面撰写规范见 `skills/_shared/conventions/llmwiki-bge-m3-conventions.md`。
